🎯 ภาพรวมระบบ

ZTOP EA V4 เป็น Expert Advisor สำหรับ MetaTrader 5 ที่ใช้กลยุทธ์ Momentum Spike Breakout ตรวจจับสัญญาณจากอินดิเคเตอร์ ZigZag และวางคำสั่งแบบ Pending Order (BuyStop/SellStop) โดยอัตโนมัติ

✨ จุดเด่น

  • ✅ ระบบวางคำสั่งแบบคู่ (BuyStop + SellStop)
  • ✅ ตัวกรองสัญญาณขั้นสูง 10 เงื่อนไข (เลือกเปิด-ปิดได้)
  • ✅ จัดการความเสี่ยงอัตโนมัติ: TP/SL, Trailing, Break-Even
  • ✅ แดชบอร์ดแสดงสถานะแบบเรียลไทม์
  • ✅ จำกัดกำไร/ขาดทุนรายวันได้

📊 เหมาะสำหรับ

  • • เทรดเดอร์ที่ต้องการระบบอัตโนมัติ
  • • ผู้ใช้บัญชี Prop Firm ที่ต้องการควบคุมความเสี่ยง
  • • การเทรดทองคำ (XAUUSD) และคู่เงินหลัก
  • • Timeframe แนะนำ: M15 - H4

คำเตือน: การเทรดมีความเสี่ยงสูง ผู้ใช้ควรทดสอบในบัญชีเดโมก่อนใช้งานจริง และเข้าใจพารามิเตอร์ทุกตัวอย่างถ่องแท้

⚙️ การติดตั้งบน MetaTrader 5

1

ดาวน์โหลดและแตกไฟล์

ดาวน์โหลดจากลิงก์ด้านบน แล้วแตกไฟล์ .zip ออกมา

2

คัดลอกไฟล์ไปยังโฟลเดอร์ MT5

📁 MQL5/Experts/ → วางไฟล์ ZTOP EA V4.ex5

📁 MQL5/Indicators/ → วางไฟล์ ZigzagColor.ex5 และ ZZArrow.ex5

3

เปิดใช้งานการเทรดอัตโนมัติ

  • • ใน MT5: Tools → Options → Expert Advisors
  • • ☑ Allow algorithmic trading
  • • ☑ Allow WebRequest (จำเป็นสำหรับระบบยืนยันตัวตน)
  • • เพิ่ม URL: https://script.google.com
4

ลากวางและตั้งค่า

ลาก ZTOP EA V4 ลงบนชาร์ต > ปรับพารามิเตอร์ > กด OK

คำแนะนำด่วน: เริ่มต้นด้วยค่าเริ่มต้นทั้งหมดก่อน ทดสอบในเดโมอย่างน้อย 1 สัปดาห์ แล้วค่อยปรับพารามิเตอร์ตามสไตล์การเทรดของคุณ

📋 พารามิเตอร์สำคัญ

พารามิเตอร์ ค่าเริ่มต้น คำอธิบาย
InpDepth 12 ความลึกของการค้นหาจุดกลับตัวใน ZigZag
InpLotSize 0.01 ขนาดล็อตพื้นฐาน
InpStopLossPoints 1000 ระยะ Stop Loss (หน่วย: จุด)
InpTakeProfitPoints 5000 ระยะ Take Profit (หน่วย: จุด)
InpUseAdvFilter false เปิดใช้งานตัวกรองสัญญาณขั้นสูง
InpFilterMinConditions 3 จำนวนเงื่อนไขขั้นต่ำที่ต้องผ่าน (จากที่เปิดใช้งาน)
InpUseDailyProfit false หยุดเทรดเมื่อถึงเป้ากำไรรายวัน

* ดูพารามิเตอร์ทั้งหมดในไฟล์ .set หรือในหน้าตั้งค่าของ EA
