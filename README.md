## 📋 About

ZTOP EA V4.00 is a Momentum Spike Breakout Expert Advisor for MetaTrader 5. This repository contains the HTML manual with comprehensive documentation in Thai and English.

### Features

- 🇹🇭🇬🇧 **Bilingual Support** - Thai/English language switching
- 📱 **Responsive Design** - Mobile and desktop optimized
- ⚡ **Fast Loading** - Tailwind CSS CDN integration
- 🎨 **Modern UI** - Clean and intuitive interface
- 🔧 **Interactive Elements** - Language switcher, floating action button
